# Heart-Disease-Health-Indicators-Dataset

Osztályegyensúly a szívbetegség-felmérésben
Kérdés. Mennyire különíthetők el a kérdőív alapján azok, akik korábbi koszorúér-betegségről
vagy szívinfarktusról számoltak be?
Tervezés. Használd a HeartDiseaseorAttack dokumentált kódolását. Ellenőrizd az
osztályarányokat, a sorrendi kategóriákat és azokat a változókat, amelyek az esemény utáni
állapotot tükrözhetik. Rétegzett felosztással hasonlíts össze egy gyakoriságon alapuló
alapmodellt és egy értelmezhető osztályozót. A küszöbértékeket a validációs adatokon
válaszd ki. Az értékelő adatokban tartsd meg az eredeti osztályarányokat.
Eredmények. Közöld a precision-recall görbe alatti területet a pozitív osztály arányával
együtt. Két előre kiválasztott küszöbnél add meg a téves pozitív és negatív esetek számát
1000 válaszadóra vetítve. Mutass be egy alcsoport-összehasonlítást az elemszámokkal. A
kimenetet a résztvevők által közölt előzményként értelmezd.
Védés. Hogyan lehet magas az összpontosság, ha az osztályozó sok pozitív esetet kihagy? Mi
változik egy lehetséges esemény utáni változó elhagyásakor?
